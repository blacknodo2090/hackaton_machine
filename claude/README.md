# Claude

Abre la carpeta raíz del proyecto en Claude Code. Las instrucciones automáticas
están en `../CLAUDE.md`. Lee `CONTEXT.md` para las notas de Claude y
`../docs/COMMON_CONTEXT.md` para el contexto común y sus fuentes de verdad.

Autentica Claude Code localmente según la documentación oficial. No guardes
tokens en esta carpeta ni añadas permisos amplios sin revisarlos con el equipo.
