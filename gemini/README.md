# Gemini

Abre la carpeta raíz del proyecto en Gemini CLI. Las instrucciones automáticas
están en `../GEMINI.md`. Lee `CONTEXT.md` para las notas de Gemini y
`../docs/COMMON_CONTEXT.md` para el contexto común y sus fuentes de verdad.

Autentica Gemini CLI localmente según la documentación oficial. Revisa cualquier
configuración de herramientas antes de habilitarla.
