# Codex

Abre la carpeta raíz del proyecto en Codex. Las instrucciones automáticas están
en `../AGENTS.md`. Lee `CONTEXT.md` para las notas de Codex y
`../docs/COMMON_CONTEXT.md` para el contexto común y sus fuentes de verdad.

Autentica Codex localmente según la documentación oficial. Revisa cualquier
configuración de permisos antes de habilitarla.
